# 预测差距：诚实账簿（2026-10-20）

> 用户之问: "我们是否计算出了所有大模型的困惑?" —— 即: 是否达到牛顿标准——
> 从第一性原理**先验算出**任意 (架构, 参数, 数据) 的困惑度, 无需训练。
> **答案: 没有。** 本文记账: 有什么、缺什么、差多远、怎么补。

## 1. 牛顿标准 vs 现状

牛顿: 给定质量与初值, **先验算出**轨道, 无需观测天体。
认知动力学的对应标准: 给定 (架构, N, 数据 𝒫), **先验算出** L(N, 𝒫),
无需训练。现状: **不能**。我们能算**界限**, 不能算**数值**。

## 2. 诚实账簿: 已证 / 半证 / 未证

### ✅ 已机器验证（Lean, 94 定理中的相关部分）
| 内容 | 定理 | 对"算困惑"的作用 |
|---|---|---|
| 交叉熵 ≥ 数据熵 | `pretraining_loss_lower_bound`（InfoDynamics） | **任何模型任何数据的困惑度绝对下界**——从下界锚定 |
| 容量计数: R 比特 ⟹ ≤2^R 状态 | LMT.lean 容量定理 | 参数能表达的状态数上限——从上界锚定 |
| 每参数交互率（注意力 n²/(3d²) 等） | Efficiency.lean 8 定理 | 架构的"轴 2 容量"定量式 |
| 组合容量 2^k | CognitiveDynamics.lean | 容量随参数的结构增长 |
| L = c/(N+1)^α 递减形状 | `scaling_law_strict_anti`（Training） | 规模律的**结构**形状 |
| L4 最优深度有限 | `optimal_depth_is_first_crossing` | 深度维度的最优停时 |
| L6 softmax 最优性（半程） | Gibbs.lean 5 定理 | 选择算子形式 |

⟹ **我们已能给出任何大模型困惑度的 provable 双重界限**（熵下界 + 容量上界）,
但界限之间的宽度就是理论缺口。

### ⚠️ 半证（推导路线图 + 实验方向支持）
- L2 规模律: E9 双区间实验 + 谱尾故事, 无先验预测公式
- L3 吸引子/临界: E8A 普适性复现 + 8C 相关, 无预测力
- L7 反向传播: 12.5× 实验 + 文献定理
- L8 残差: 定理+实验双全（这是最完整的一条）
- 五组件推导（注意力/残差/规模）: 论证非定理

### ❌ 未证（关键缺口）
1. **感知流谱 {λ_i} 的先验测定**: 率-失真函数 R(D) 的输入是数据协方差谱,
   我们从未从数据**测量**它再**预测**损失
2. **架构 → 可达率 R(N) 的封闭映射**: 有效秩如何随 N/架构变化, 只有
   UWS 的经验数字（≤16 方向）, 无推导
3. **优化缺口**: 训练动力学收敛到率-失真最优的比例——**零理论**
   （edge-of-chaos/Lyapunov 是候选入口, 未接上）
4. **先验预测公式本身**: L̂(N, T, 𝒫) = ? 不存在

## 3. 缺口的具体宽度（用 E9 数据定位）

E9 实测: dim=24, T=160K ⟹ L = 2.61 nats/char; vocab≈1339 ⟹ 随机基线 7.20 nats。
- 下界侧: 英文类文本的字符级条件熵（无限上下文）约 1.3–1.8 nats——
  可用 **LZMA/xz 压缩率**实测估计（Kolmogorov 复杂度的可行代理）
- 中间 2.61 vs 下界 ~1.5 的差 = 容量不足 + 优化缺口 + 估计误差三项混合
- **理论任务就是把这三项分解开并逐项先验计算**——目前一项都不能单独算

## 4. 补缺路径: E13（第一个真正的先验预测实验）

这是从"界限"走到"数值"的关键实验, 全部组件已就绪:
1. **测数据谱**: 对语料做上下文→下一字符的统计矩阵 SVD（E8 的谱分析机器
   直接用）, 得 {λ_i}, 拟合幂律指数（对照 UWS 的 α∈[2,6]）
2. **测熵地板**: xz 压缩率 → H_floor 代理
3. **组装预测**: L̂(N, T) = H_floor(T) + C·I(N)^{-β}, 其中 I(N) = 交互计数
   （Efficiency.lean 的公式）, C/β 只从**数据谱**拟合（不碰 E9 的 loss 数据）
4. **检验**: 用 L̂ 预测 E9 网格的 9 个 (N, T) 点的 loss, 与实测对照
5. **判定**: 预测误差 < 训练噪声（±0.2 nats）⟹ 第一个先验预测成立;
   否则分解三项找原因（这是最有信息量的失败）

**为什么这个实验是分水岭**: E8-E12 全是"训练后测量"（现象学）; E13 是
"先验计算后对照"（预测性）——后者才是牛顿标准的检验。公式里的每一块都有
Lean 已证内核或可测输入, 不是空中楼阁。

## 5. 时间线的诚实估计

| 里程碑 | 依赖 | 状态 |
|---|---|---|
|  provable 界限（任何模型的困惑度上下界） | 已有定理 | ✅ 已完成 |
| E13 先验预测（单语料单架构族） | 谱测量 + 组装 | 可立即做（CPU 数小时） |
| 跨架构预测（RNN/CNN/Transformer 通用公式） | R(N) 封闭映射 | 需新推导（周级） |
| 优化缺口理论（收敛率） | Lyapunov/临界性接轨 | 开放问题（月级） |
| "算出所有大模型的困惑" | 以上全部 + 数据谱普适性 | 研究计划, 非近期 |

## 6. 结论

- **已解决**: 本体与公设（极小化到 1 条）、动力学定律的形式（A4 + 推导链）、
  两条机器验证定律（L4/L6 半程）、困惑度的 provable 界限、五组件的
  论证级解释、六个方向性实验
- **未解决**: 先验数值预测（牛顿标准的核心）、R(N) 封闭映射、优化缺口
- **当前正确定位**: 开普勒阶段——有经验律（规模律、普适性、坍缩相变）和
  若干已证定理, 但还没有"原理"那一步的预测公式。E13 是走向原理的第一步。
