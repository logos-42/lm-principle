# 预测差距：诚实账簿（2026-10-20）

> 用户之问: "我们是否计算出了所有大模型的困惑?" —— 即: 是否达到牛顿标准——
> 从第一性原理**先验算出**任意 (架构, 参数, 数据) 的困惑度, 无需训练。
> **答案: 没有。** 本文记账: 有什么、缺什么、差多远、怎么补。

## 1. 牛顿标准 vs 现状

牛顿: 给定质量与初值, **先验算出**轨道, 无需观测天体。
认知动力学的对应标准: 给定 (架构, N, 数据 𝒫), **先验算出** L(N, 𝒫),
无需训练。现状: **不能**。我们能算**界限**, 不能算**数值**。

## 2. 诚实账簿: 已证 / 半证 / 未证

### ✅ 已机器验证（Lean, 94 定理中的相关部分）
| 内容 | 定理 | 对"算困惑"的作用 |
|---|---|---|
| 交叉熵 ≥ 数据熵 | `pretraining_loss_lower_bound`（InfoDynamics） | **任何模型任何数据的困惑度绝对下界**——从下界锚定 |
| 容量计数: R 比特 ⟹ ≤2^R 状态 | LMT.lean 容量定理 | 参数能表达的状态数上限——从上界锚定 |
| 每参数交互率（注意力 n²/(3d²) 等） | Efficiency.lean 8 定理 | 架构的"轴 2 容量"定量式 |
| 组合容量 2^k | CognitiveDynamics.lean | 容量随参数的结构增长 |
| L = c/(N+1)^α 递减形状 | `scaling_law_strict_anti`（Training） | 规模律的**结构**形状 |
| L4 最优深度有限 | `optimal_depth_is_first_crossing` | 深度维度的最优停时 |
| L6 softmax 最优性（半程） | Gibbs.lean 5 定理 | 选择算子形式 |

⟹ **我们已能给出任何大模型困惑度的 provable 双重界限**（熵下界 + 容量上界）,
但界限之间的宽度就是理论缺口。

### ⚠️ 半证（推导路线图 + 实验方向支持）
- L2 规模律: E9 双区间实验 + 谱尾故事, 无先验预测公式
- L3 吸引子/临界: E8A 普适性复现 + 8C 相关, 无预测力
- L7 反向传播: 12.5× 实验 + 文献定理
- L8 残差: 定理+实验双全（这是最完整的一条）
- 五组件推导（注意力/残差/规模）: 论证非定理

### ❌ 未证（关键缺口）
1. **感知流谱 {λ_i} 的先验测定**: 率-失真函数 R(D) 的输入是数据协方差谱,
   我们从未从数据**测量**它再**预测**损失
   → 🟡 **E13 已测**（α≈2.0–2.4, 有效秩 20→40）; 谱可测, 但"谱 → 损失"的组装仍缺一项
2. **架构 → 可达率 R(N) 的封闭映射**: 有效秩如何随 N/架构变化, 只有
   UWS 的经验数字（≤16 方向）, 无推导
   → 🟡 **E13 已定位为二变量 R(N,T)**: 每个 T 内是干净幂律（R²=0.97）但 γ 依赖 T
   （0.067/0.121/0.166）; 计数型 R(N)=ln(N·n²/3d²) 被数据否掉（几乎不随 N 变）
3. **优化缺口**: 训练动力学收敛到率-失真最优的比例——**零理论**
   （edge-of-chaos/Lyapunov 是候选入口, 未接上）
   → 🟡 **E13 测得 ≈0**: 训练损失可低于熵地板（记忆化）⟹ 绑定项是 test−train 的泛化/估计
4. **先验预测公式本身**: L̂(N, T, 𝒫) = ? 不存在
   → ❌ 仍不存在: E13 的第一版公式 **MAE 0.472 nats**（噪声 0.019）未过判据,
   失败诊断为"缺 T 项"

## 3. 缺口的具体宽度（用 E9 数据定位）

E9 实测: dim=24, T=160K ⟹ L = 2.61 nats/char; vocab≈1339 ⟹ 随机基线 7.20 nats。
- 下界侧: 英文类文本的字符级条件熵（无限上下文）约 1.3–1.8 nats——
  可用 **LZMA/xz 压缩率**实测估计（Kolmogorov 复杂度的可行代理）
- 中间 2.61 vs 下界 ~1.5 的差 = 容量不足 + 优化缺口 + 估计误差三项混合
- **理论任务就是把这三项分解开并逐项先验计算**——目前一项都不能单独算

## 4. 补缺路径: E13（第一个真正的先验预测实验）

这是从"界限"走到"数值"的关键实验, 全部组件已就绪:
1. **测数据谱**: 对语料做上下文→下一字符的统计矩阵 SVD（E8 的谱分析机器
   直接用）, 得 {λ_i}, 拟合幂律指数（对照 UWS 的 α∈[2,6]）
2. **测熵地板**: xz 压缩率 → H_floor 代理
3. **组装预测**: L̂(N, T) = H_floor(T) + C·I(N)^{-β}, 其中 I(N) = 交互计数
   （Efficiency.lean 的公式）, C/β 只从**数据谱**拟合（不碰 E9 的 loss 数据）
4. **检验**: 用 L̂ 预测 E9 网格的 9 个 (N, T) 点的 loss, 与实测对照
5. **判定**: 预测误差 < 训练噪声（±0.2 nats）⟹ 第一个先验预测成立;
   否则分解三项找原因（这是最有信息量的失败）

**为什么这个实验是分水岭**: E8-E12 全是"训练后测量"（现象学）; E13 是
"先验计算后对照"（预测性）——后者才是牛顿标准的检验。公式里的每一块都有
Lean 已证内核或可测输入, 不是空中楼阁。

### 4.1 执行结果（2026-10-21, 远程 2×A100）——**未通过, 失败方式已定位**

详报 `docs/wiki/experiment-results-e13.md`（12 格 × 3 seeds = 36 次 GPU 训练）。

- 预测**训练前写盘**（sha256 2e837863d6a34d0a）, 事后对照: **MAE 0.472 nats**
  vs 训练噪声 0.019 nats ⟹ 按原判据（< ±0.2）**不成立**
- 但 12 格误差**符号随 T 翻转**: T=10K −0.877 / 40K −0.305 / 160K **+0.146**
  ⟹ 不是"系数没调对", 而是**公式缺一项 T 依赖**
- 反演诊断（实测超额在测得谱上反解所需率）给出三条定量结论:
  1. 先验 R(N)=ln(N·n²/3d²) **几乎不随 N 变**（12.48→11.68, N 变 29×）——
     因 N∝d² ⟹ R≈常数。**计数型容量界在结构上产生不出观测到的 N 斜率**
  2. 实测 R_eff 在每个 T 内是干净幂律（R²=0.97）, 但**指数 γ 依赖 T**（0.067/0.121/0.166）
     ⟹ 缺口 #2 的封闭映射是二变量的: **R(N,T)**, 单变量形式不存在
  3. R_eff 随 T 穿过先验值（T=10K 时 4.9–6.7 ≪ 12.5, T=160K 时 10.3–18.1 > 12.5）
     ⟹ 误差符号翻转的机制: 数据不足时率拿不到, 数据充足时先验偏保守
- **缺口 #3 被量出来了**: dim192/T160K 的训练损失 1.556 已**低于 xz 地板 1.628**（记忆化）
  ⟹ 优化缺口（SGD 未到最小）不是绑定项; 可达损失的绑定项是 **test−train ≈ 1.1–1.3 nats
  的泛化/估计误差**。缺口 #3 从"零理论"变为"可分离, 且主项不在优化"
- 谱侧先验量可测且稳定: α≈2.0–2.4（在 UWS suitability α∈[2,6] 内）, 有效秩 20→40,
  I(ctx;next) 2.95→3.57 nats; 地板必须用**条件压缩率**（单段 xz 在小窗虚高 0.6–1.4 nats）


## 5. 时间线的诚实估计

| 里程碑 | 依赖 | 状态 |
|---|---|---|
|  provable 界限（任何模型的困惑度上下界） | 已有定理 | ✅ 已完成 |
| E13 先验预测（单语料单架构族） | 谱测量 + 组装 | ✅ **已执行（2026-10-21, GPU）: 未通过, MAE 0.472**；失败定位 = 公式缺 T 项、R 映射是 R(N,T) |
| 跨架构预测（RNN/CNN/Transformer 通用公式） | R(N,T) 封闭映射 | 需新推导（周级）；E13 给出二变量幂律的证据与 γ(T) 的三个实测点 |
| 优化缺口理论（收敛率） | Lyapunov/临界性接轨 | 🟡 **部分回答**: E13 测得 train loss 可低于地板 ⟹ 优化非绑定项, 主项是泛化/估计 |
| "算出所有大模型的困惑" | 以上全部 + 数据谱普适性 | 研究计划, 非近期 |

## 6. 结论

- **已解决**: 本体与公设（极小化到 1 条）、动力学定律的形式（A4 + 推导链）、
  两条机器验证定律（L4/L6 半程）、困惑度的 provable 界限、五组件的
  论证级解释、六个方向性实验
- **E13 之后的账**（2026-10-21）: 先验预测**第一次被执行并失败**（MAE 0.472, 噪声 0.019）,
  但失败被精确定位——缺口 #2 是 **R(N,T)** 而非 R(N)（幂律形式对、系数随 T 变）,
  缺口 #3（优化）被量到 ≈0（train loss 可低于熵地板）, 缺口 #1（谱）已可测。
  **"算出困惑"仍差一次组装**, 但剩下的未知从"三个洞"变成"一个二变量函数 + 一个泛化项"
- **未解决**: 先验数值预测（牛顿标准的核心）、R(N,T) 封闭映射、泛化/估计项的理论
- **当前正确定位**: 开普勒阶段——有经验律（规模律、普适性、坍缩相变）和
  若干已证定理, 但还没有"原理"那一步的预测公式。E13 是走向原理的第一次实测:
  它没有给出公式, 但给出了公式必须满足的形状（N 与 T 的二变量幂律）
