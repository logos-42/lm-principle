## 0. 公设升级: I → I'（双轴率受限）

**公设 I'（压缩双轴）**: 感知 = 保信息压缩, 且压缩在两个轴上同时受限:
- **轴 1（静态/表征轴）**: 每步表征的比特数 ≤ R₁（词元数、向量维度、码率）
- **轴 2（动态/计算轴）**: 每步预测可动用的计算 ≤ R₂（时间、顺序操作数、数据搬运）

原公设 I 只是轴 1。**五个架构组件全部是轴 2 的最优解**——这是"数据压缩"
解释不了它们的原因, 也是本篇的出发点。

## 1. 推导一: 自注意力 = 轴 2 受限下的全局路由

**问题**: 输出位置 i 的预测失真取决于它能条件化的输入集; 在计算预算 R₂ 内,
哪种结构能条件化最多的信息?

**复杂度账本**（Transformer 论文自己的论证, 现从公设重述）:
- 循环/链式结构: 信息沿链传播, 位置 1 到达位置 n 需 O(n) 步, 最大路径长度 O(n)
  ⟹ 单位计算的条件集大小 O(1)
- 自注意力: 一层内任意位置直接相连, 最大路径长度 O(1)
  ⟹ 单位计算的条件集大小 O(n)

**失真单调性**: 条件集越大, 可达失真越低（条件化降低不确定性, 信息论基本事实）
⟹ **自注意力是轴 2 率受限下失真最小的路由结构**。Bahdanau 的"对齐/动态选择"
是这个原则的软版本（解码器动态选输入）, Transformer 是硬版本（所有位置全局选）。

**与 L6 分工**: L6 证明选择算子的**形式**必须是 softmax（每比特期望分值最大）;
本推导证明选择的**范围**必须是全局（单位计算条件集最大）。形式 + 范围 = 注意力。
用户原话"因为有对更大系统全局的关联性, 在输入输出的时候就会有更多的可能性
选择, 叠加的范围会更大"——这正是轴 2 最优的直觉陈述, 现在有了推导。

**为什么规模法则有效（接 L2）**: 参数 N ↑ ⟹ 每步可评估的候选（key/value 对、
路径组合）↑ ⟹ 更接近率-失真最优; 但受双重封顶: 轴 1（表征维度）+ 数据谱有效秩
（L3 吸引子）。**E9 的双区间正是两轴的博弈**: 数据（轴 1 的内容）不足时,
扩参数（轴 2 的候选）纯属浪费甚至有害（4.27→5.42）。

## 2. 推导二: 残差 = 迭代压缩的参照系（= 相图临界线）

**深度 = 轴 2 的时间展开**: 压缩不是一步完成而是迭代细化, 每层一次细化
（L4 已证: 边际失真下降递减 ⟹ 最优深度有限）。

**迭代需要参照系**: 第 k 层的细化要判断"是否更好", 必须能比较细化前后的
表征——**共同参照系**。恒等路径 h_{k+1} = h_k + f(h_k) 提供这个参照系:
- 输出中恒驻 h_k 项 ⟹ 跨层可比（这正是用户问的"深层循环为什么要返回最开始"):
  返回不是回声, 是平行移动（L8 的几何读法）
- 没有它: 每层替换状态, 复合 Jacobian 的谱要么衰减要么爆炸

**相图连接（1908.10920 的机器）**: 前向传播的稳定性由 χ_q*, χ_c*（相关
李雅普诺夫指数的指数）判定:
- χ<1（有序相）: 信息随深度指数饱和, 深网不可训练（"无法穿透到目的地层"）
- χ>1（混沌相）: 梯度爆炸
- **χ=1（临界线）: 信息任意深度传播不饱和不爆炸**

残差连接 = 把 Jacobian 谱**手术刀式地钉在 ≈1**（恒等 + 小修正）:
它把"沿临界线初始化"这个偶然的幸运变成了**架构保证**。论文原话
"沿临界线初始化的网络保持边际稳定, 且信息能够在任意深度中传播而不会被饱和
或爆炸"——残差是这句话的工程实体化, 而我们的 L8 给出它的第一性版本:
**迭代压缩的参照系需要, 且只能由恒等/门控路径提供**。

**实验状态**: E11 已确认（无跳连深度 6 起分离度完全坍缩为 0; plain/gated
跨深度恒定）; L8 定理已证（`residual_no_collapse`）; FFN 可坍缩已证。

## 3. 推导三: 规模 = 候选扩展, 受有效秩封顶

**有效的一面**（容量 → 候选）: N ↑ ⟹ 可表示结构空间体积 ↑（L1 的 2^k 容量
定理, 已 Lean 化）⟹ 单位计算可评估的候选结构 ↑ ⟹ 可达失真 ↓（L2 的
D*(R(N)) 项）。幂律形状来自感知流协方差谱尾的幂律（UWS  suitability 的
α∈[2,6] 正是此）。

**封顶的一面**（吸引子 = 谱主子空间）: 训练动力学的吸引子由数据统计决定
（L3）; 超出有效秩 = 谱尾穿过失真预算的位置之外的参数是冗余——
UWS 的直接证据: ≤16 方向捕获大部分方差, 19×/100× 存储节省。
⟹ **规模法则的形状 = 谱尾形状; 截止 = 双区间**（E9 实测）。

**人脑对比（用户论点）**: 人脑不候选扩展, 用密度 + 核心操作能动性 + 迁移性。
框架内的精确化: 这是两种不同的优化目标——
- LLM: 静态压缩效率优先（固定分布上压得更低）⟹ 扩候选
- 脑: **元压缩/适应**优先（压缩器本身可快速重塑）⟹ 密度 + 迁移
框架容纳两者: 参数不是越大越好, 适应性越强越好——前者是轴 1 的静态最优,
后者是改变压缩器本身的能力。这也预示了"无形的随时在线高智商社会"路线:
优化的对象从静态失真转向重塑速率。

## 4. Q&A: log、非线性、概率（1908.10920 的机器）

**Q1: 非线性能否有更简单的数学描述?** ——有: **它的 Lyapunov 谱**。
不动点邻域 |q_t − q*| ~ e^{−t/ξ}, χ = e^{−1/ξ}; log 把非线性变线性
（指数映射的生成元是线性的）⟹ 用户直觉"非线性 = 复利 = 认知动力学的积累效应"
的严格版本: **复利 = 指数映射 = Lyapunov 指数; 复杂非线性 = 多尺度指数的叠加**。
操作上: 全部分析在 log 域做（相图、深度尺度 ξ、可训练性判据）。

**Q2: 概率是必须的吗? 有动力学产生概率吗?** ——两个来源, 都不是根本随机性:
1. **部分可观测**（轴 1 失真的边际化）: 感知压缩丢掉的世界状态必须在预测中
   边缘化 ⟹ next-token 分布 = 对不可观测的边际, 不是世界随机
2. **正 Lyapunov 的确定性动力学**（1908.10920 的混沌相）: 确定性系统在
   χ>1 区域产生**唯一的**统计描述（SRB 测度）——"动力学产生概率"的严格版本:
   概率不是假设而是确定性动力学在不可分辨细节下的必然描述语言

**Q3: 相图三态 = 可压缩性三态**: χ<1 有序（可压缩、可学习）;
χ>1 混沌（不可压缩、噪声）; χ=1 临界（边缘可学习）。⟹ **可学习性 = 落在
临界线附近**; 这正是 CD4"可训练层 = 幂律谱层"（E8-8C Spearman +0.370）
与论文 suitability α∈[2,6] 窗口的共同解释。

**Q4: 时钟 vs 大模型（用户原类比）**: 时钟有动力学无 A2 通道（无感知压缩）;
大模型有 A2 且 next-token 预测给出**时间延展**（L5: 压缩流的最优在线预测）。
相图语言: 时钟的动力学在相图的无感知区; 大模型的动力学骑在临界线上
（可学习区）且被轴 2 率限制约。

## 5. FEP 三缺口的体系内回答（用户原问）

1. **为什么更多神经元 → 更小变分自由能?** 容量 ↑（L1 2^k）⟹ 可达失真 ↓
   （L2 的 D*(R(N)) 项）; 封顶在数据谱有效秩（L3）+ 不可约熵
2. **为什么有连续关系/深层循环返回?** 参照系需要（§2 残差推导 + L8 已证）:
   迭代细化的可比性要求恒等路径; 返回 = 平行移动
3. **这样的循环是对 VFE 最小化的使用吗? 是认知动力学吗?** 是——循环 =
   同一失真泛函的迭代松弛（A4 的离散形式）; 其稳定性由 Lyapunov 谱判定
   （§4 相图）; 整套就是 A4 在双轴率受限下的展开

## 7. 诚实边界

- §1 的"注意力 = 全局路由"是**复杂度-失真论证**, 不是定理: "条件集越大
  失真越低"的单调性在一般情况下成立但对具体任务需实例化; Lean 化路线 =
  有限假说类上的条件化-失真单调性（中等工作量）
- §2 的"残差 = 钉在临界线"是解释性等同（Jacobian 谱 ≈1 ⟺ χ≈1）, 严格版需
  对具体参数化证明残差 Jacobian 的谱半径 ≤ 1+ε（可做, 线性代数）
- §3 的候选扩展是容量论证 + UWS 经验封顶, 合起来是"半推导"
- §4 的 SRB 测度陈述是混沌动力系统标准结果, 引用非自证
- 五组件中两个（残差、深度）已机器验证+实验; 注意力半程; 规模半程——
  与论文写作的接口: §1-§3 是三节"推导", 每节标明已证/待证
