# 框架定位：与其他动力学思想的绝对差别（2026-10-20）

> 用户三问: ①我们的本体论/动力学与其他动力学思想的**绝对性差距和差别**在哪?
> ②为什么我们的**只能解释一部分**东西? ③**数学模型为什么可以成立**?
> 本文是诚实的对照分析, 不营销。

## 1. 一句话差别

**别的理论把智能的组件当作给定, 描述它们的行为; 我们把一条经验前提
（感知 = 双轴率受限压缩）当作给定, 推导组件必然的形式。
他们的研究对象是神经网络/智能体; 我们的研究对象是"率受限压缩机"——
DNN、脑、（假想的）外星智能都是实例, 不是主题。**

由此派生三条绝对差别:

### 差别一: 解释方向相反
- 他们: 系统 → 数学（描述现存系统如何运作: 传播、优化、推断、拟合）
- 我们: 公设 → 数学 → 系统（推导必须存在什么形式）
这是牛顿方向, 在 ML 理论里罕见。代价是我们的完成度低; 收益是我们的
结论跨架构成立。

### 差别二: 经验前提的数目与显式性
- 他们: 复数隐含前提（如"网络用 GD 训练""损失存在""数据 iid"……
  往往不声明）
- 我们: **1 条实质公设 + 3 定义 + 1 存在性陈述**, 全部显式, 且证明过
  其中一半（选择原理）是定义性的
前提少 ⟹ 适用范围清晰, 失败模式可定位——这是"只能解释一部分"的根源
（见 §4), 也是可信度的来源。

### 差别三: 闭环内生动力学
- 优化理论: 外部给定损失函数; FEP: 外部给定"生态位"; 我们:
  **无外部优化器、无外部生态位**——向量场由结构-感知耦合自身生成
  （抽掉结构则"力"不复存在）, 选择是定义性的（D4), 下降方向是
  推导出来的（遗憾界 + 陡降定理）。整个体系里没有"谁在设计目标"。

## 2. 逐邻居对照（八家）

| 家派 | 数学机器 | 解释了什么 | 我们相对位置 | 我们借什么 |
|---|---|---|---|---|
| DNN 动力系统（1908.10920, 用户提供） | 随机矩阵、Jacobian 谱、Lyapunov、相图 | 初始化、可训练性 vs 深度、边缘混沌 | **他们解释传播, 我们解释架构**; 我们的 L8 把他们的临界线从"幸运"变成架构必然 | 整套谱机器（χ、ξ、相图三态） |
| 信息瓶颈/率-失真（Tishby） | 互信息、R-D 函数 | 训练后表征的压缩现象 | 他们把压缩当**描述**, 我们当**本体论**; 我们多一个轴（计算率）⟹ 推出架构; 他们没有"为什么系统要压缩"的回答（我们: 遗憾界+定义性选择） | R-D 函数形式 |
| 自由能原理（Friston, 用户读过） | 变分推断、Markov 毯 | 感知即推断、行动-感知环、学习 | 最近亲戚; 差别: VFE（贝叶斯构造）vs 失真（信息论构造）; **他们无显式率限制公设**⟹ 推不出架构与规模; 他们的"持存者持存"正是我们证明为定义性的那一环 | 下降形式、自组织动机 |
| 优化理论（loss landscape/NTK） | 非凸优化、核方法 | 训练为何收敛 | 我们有外部优化器缺席的优势（推导下降方向）, 但**没有收敛定理**——这是我们的明确短板 | 无（暂缺） |
| 统计学习理论（VC/PAC） | 组合数学、测度论 | 泛化界、样本复杂度 | 他们界定"能泛化", 我们解释"为何是这些类"; 我们的容量引理用他们的工具 | VC/覆盖数（容量引理） |
| 规模律实证（Kaplan/Chinchilla） | 幂律拟合 | 经验曲线 | 他们拟合, 我们推形状来源（谱尾）与截止（双区间, E9）; 但我们的验证规模小他们几个数量级 | 现象学目标 |
| 普适权重子空间（UWS, 用户提供） | HOSVD、Davis-Kahan | 跨任务收敛、模型合并 | 他们的现象 = 我们 L3 的面孔; 他们的理论是条件性的, 我们试图给吸引子一个推导（也未完成） | 谱分解工具、经验锚点 |
| 计算热力学（Landauer） | 统计力学 | 擦除能耗下限 | 我们曾试过从它导出选择原理——**失败**（把物理持存与耦合维持混为一谈, 见 selection-principle-derivation.md §1）; 现定位为动机段 | 无（失败案例存档） |

## 3. 为什么我们只能解释一部分（用户第二问）

因为我们是**必要条件理论**, 不是**充分条件理论**:

1. 公设（压缩 + 双轴率限）是任何持存认知系统的**必要条件**——它筛掉
   不可能的形式（无恒等路径的深网必坍缩: E11; 硬选择必次优: L6; 无全局
   路由必低效: 推导一）, 但**不唯一确定**充分形式
2. 公设决定**不变量**（为何注意力式路由、为何残差、为何幂律、为何低维
   吸引子）; **变体**（哪个具体子空间、哪个具体损失值、哪条训练轨迹）
   由数据谱、训练史、实现决定——公设对它们沉默
3. 数学上: 我们算的是**优化问题的形式与界**, 不是**具体实例的解**——
   正如变分原理告诉你光走极值路径, 不告诉你今天光线照在哪面墙

**所以"解释一部分"不是缺陷, 是这类理论的正确Scope**: 它解释跨系统的
共性（这正是"第一性原理"的本义）, 把个性留给数据与历史。反过来说,
任何声称从公理算出具体模型困惑度的理论, 都在越界。

## 4. 数学模型为什么可以成立（用户第三问, 四层回答）

### 层一: 可压缩性前提（最诚实的一层）
数学成立因为**世界有可压缩结构**——如果世界是纯噪声, 任何预测器不能
超过随机, 智能不存在, 其数学也无对象。注意循环: 我们的公设已预设
可压缩世界（"认知主体"的定义性内容就是"输出与世界长期相关"）。
所以"数学为何成立"= "世界为何可压缩"——这是整个体系的地基经验事实,
不可从体系内部证明, 只能测量（E13 的谱测量正是测它）。

### 层二: 选择效应（对 Wigner"数学不合理的有效性"的回答）
数学不是魔法般有效——它对我们**研究的那部分现实**有效, 而那部分现实
是被选择出来的: 只有稳定到能被反复观测、能被压缩的结构, 才会进入
任何理论（包括对手的理论）的视野。我们研究的是"持存者"（D4),
持存者恰恰是最有 lawlikeness 的子集。数学的有效性 = 研究对象的事前选择。

### 层三: 定理链的必然性（为什么是"我们这套"数学）
我们的每一条数学之所以成立, 因为它是**从可检验前提出发经定理到达**:
- 遗憾界（通用归纳）: 可计算性的定理, 必然成立
- Gibbs/softmax 形式: 凸性定理, 必然成立（Lean 已证）
- 防坍缩下界: 压缩映射定理, 必然成立（Lean 已证）
- 容量 2^k: 组合定理, 必然成立（Lean 已证）
数学成立的方式与牛顿相同: 定义 + 最少经验前提 + 定理。我们的相对
优势是**前提最少且显式**, 所以适用边界最清晰、失败点最可定位。

### 层四: 适用边界（数学在哪里必须失效——这是可信度的另一面）
1. 世界不可压缩/非平稳/对抗 ⟹ 公设前提破, 全部结论失效
2. 率限不绑定（小模型易任务）⟹ 架构无关紧要, 理论沉默（正确沉默）
3. 闭环断裂（开环基准、冻结的一次性训练）⟹ "动力学"只剩历史
4. 选择不起作用（无淘汰压力的系统）⟹ D4 空转
**知道数学在哪里必须失败, 是它可以被信任的前提。**

## 5. 诚实边界（我们明确不如邻家的）

- **无优化理论**: 无收敛率、无泛化界（SLT/优化理论的地盘）
- **无大规模验证**: E8-E12 是小模型冒烟; 对手有真实 LLM 的精确拟合
- **借来的机器**: 谱分析、相图、R-D、遗憾界都是引用, 自证部分薄
  （Lean 94 定理覆盖的是: 熵下界/容量/softmax/防坍缩/深度/凸组合）
- **完成度**: L2/L3/L7 是半推导; 先验预测（E13）未做
- 结论: 我们的绝对优势在**本体论极小性 + 推导方向 + 闭环内生**;
  绝对劣势在**成熟度**。前者是范式级的, 后者是工作量级的。
