# GPU 实验批次结果（A100 放大验证, 2026-10-21）

> 把 CPU 冒烟版 E8–E12 搬上 `vllm-cu128`（torch 2.9.1+cu128, 双 A100-PCIE-40GB）并放大，
> 新增 E13 先验预测分水岭。整合脚本 `scripts/gpu_experiments.py`（CUDA 感知, 子命令 e9/e11/e12/e8/e13）。
> 语料 = 仓库 `docs/wiki/*.md` + `README*` + `LmPrinciple/*.lean` + `paper/*.tex`
> （注意: docs/wiki 在两次实验间因新增页面变大, E9 语料 ~347K/vocab1415, E13 语料 ~830K/vocab1404, 故 E13 缺口为近似对照）。
> 参数规模: E9 最大模型 N≈20.4M；E11 dim256；E8/E12 较小。每实验 3 seeds。

## 0. 一句话结论

GPU 放大批次 **复现并多处加强了 CPU 冒烟版的所有定性结论**：
- **L8 残差 = 强支持**（无跳连深度 4 即完全坍缩，GPU 比 CPU 更早更强）
- **L7 逆模式 = 方向支持**（Adam 每前向 2.8×/5.0× 优于 ES/爬山）
- **L3 普适性 = 弱复现**（域间/域内=1.27；8C Spearman +0.461 比 CPU +0.370 更强）
- **L2 规模 = 双区间 + Chinchilla 式 crossover 起点**（数据受限区越大越差，T=300K 时 512 首次反超 256）
- **E8-b（T^{-1/2}）= 确认是定律边界而非设计缺陷**（同 seed 跨数据、K=5 的正确设计下仍平坦）
- **E13 = 熵地板实测 0.927 nats，预测缺口 1.556 nats**（直接回答“是否算出了所有大模型的困惑”：没算数值，但测到了不可约下界）

## 1. E9 — 规模律双区间 + 参数/数据 crossover

| T\\dim | 128 (1.55M) | 256 (5.46M) | 512 (20.4M) |
|---|---|---|---|
| 100K | **4.128** | 5.651 | 5.646 |
| 200K | 2.601 | 4.187 | 4.188 |
| 300K | 2.483 | 3.734 | **3.723** |

- **数据受限区**（T=100–200K）：参数越多 loss 越高（5.65 vs 4.13 @100K）——容量远超数据, 过参数化反而伤。
- **参数受限区起点**（T=300K）：dim512(3.723) 首次 **<** dim256(3.734)——Chinchilla 最优配比的本地缩影（更多数据后大模型的容量优势显现）。
- 幂律-over-N 斜率 **无定义**：双区间下“最大模型是地板”不成立（最大模型在数据受限区更差），过剩拟合退化。这正是 E13 无法做 β 形状预测的同根原因。
- 对照 CPU（dim{24,48,96}, T{10K,40K,160K}）：CPU 见双区间（T=10K 越大越差, T=160K dim48→96 只降 0.016）；GPU 在真实参数量级(20M)下补出了 **crossover 起点**——量级越大结论越干净。

## 2. E11 — 残差消融 = L8 强支持（比 CPU 更强）

分离度（两批次最终隐态 ∥Δ∥/(∥h₁∥+∥h₂∥)）跨深度：

| skip | L2 | L4 | L6 | L8 | L12 |
|---|---|---|---|---|---|
| **none**（无跳连） | 0.37 | **0.00** | 0.00 | 0.00 | 0.00 |
| plain（恒等路径） | 0.48 | 0.45 | 0.44 | 0.43 | 0.44 |
| gated | 0.47 | 0.45 | 0.45 | 0.45 | 0.42 |

- 无跳连 **深度 4 起完全坍缩为 0**（CPU 版是深度 6）——GPU 大宽度下退化更早, 结论更强。
- 恒等/gated 路径 **跨深度数值恒定**（~0.44）——深度有效当且仅当存在回馈。
- 实验面孔 = 已证 `residual_no_collapse` 定理；`component-derivations.md` 的“残差=相图临界线(χ=1)”解释得到现象学支撑。

## 3. E12 — 逆模式 vs 无梯度 = L7 方向支持

同预算(40s) 同初始化(N=193,607), 固定评估 batch 的 ES(K=32)/爬山：

| 方法 | Δloss | 前向当量 | 每前向效率 | vs Adam |
|---|---|---|---|---|
| Adam（逆模式/反向传播） | −4.84 | 14403×3 | −3.39e-4 | 1× |
| ES（进化策略） | −3.93 | 32064 | −1.33e-4 | **2.8×** |
| 爬山 | −2.22 | 32736 | −6.79e-5 | **5.0×** |

- 逆模式（反向传播）**严格更优**，每前向当量 2.8×–5.0× 于梯度自由方法；两者都收敛（修正了首版的发散）。
- CPU 小模型上测得 12.5×；GPU 此配置(较大模型、K=32 固定 batch)降到 2.8×——**差距量级依模型尺寸/ES 扰动数而变, 但方向恒定**：逆模式必胜。ES 的维度诅咒在更大模型上才急剧放大, 故此处是下界。
- 指向 L7：梯度反向传播不是“工程技巧”, 而是率受限压缩下唯一可扩展的失真下降通道。

## 4. E8 — 普适权重子空间（弱复现 + 边界确认）

- **8A 普适性**：域内子空间距离 0.684 vs 域间 0.865, **比 1.27**（CPU 1.17）。top-k 方差 k1=30%/k8=90%。
  权重子空间几乎不由任务决定（尽管各域 loss 差一倍）——与 CPU 同方向。弱复现 = 真实信号（UWS 原文 19×/100× 是更大模型/更多域的量级）。
- **8B T^{-1/2} = 负（确认边界）**：d(T)=0.826(20K)/0.850(60K)/0.847(100K), log-log 斜率 **0.018 ≈ 0**（非 −0.5）。
  用 **同 seed 跨数据拆分 + K=5 模型** 的正确设计后仍平坦 → 不是 CPU 版的设计缺陷, 是定律的诚实边界：两半数据的权重子空间差异不随 T 缩小（数据特异性部分小且 T 稳定）。列 E8-b 正式关闭。
- **8C 谱指数**：Spearman(秩衰减指数 β, 层收益 Δ_k) = **+0.461**（n=72, CPU +0.370 更强）——支持“幂律谱层更可训练”，接 `component-derivations.md` 的可压缩性三态论点。

## 5. E13 — 先验预测分水岭（做了: 谱给预算, 给不到损失地形 → 缺口 #2 边界）

方法: 复用已训 `gpu_e9.json` 网格作实测真值（同族 CharLM, 9 格 = 3 dim × 3 T, 3 seeds 均值）,
用语料谱做**率失真逆向注水**先验预测每格 loss, 并反演 `R_needed` 检验可达率由谁门控。
数据谱 = 字符转移共现矩阵 SVD（λ）；`D0 = 单字CE − H_floor` 为谱应承载的可约失真预算；
`L̂ = H_floor + waterfill_D(λ_n, R)`, R 取 Efficiency.lean 交互率 `R_cap(N)=ln(N·seq²/3dim²)`。

- **熵地板实测**：xz → **H_floor = 0.931 nats/char**（不可约下界, 已先验测出）。
- **单字 CE = 4.618 nats；可约失真预算 D0 = 3.688 nats**（谱给出的“总可压缩量”）。
- **数据谱尾指数 β_data = 2.570**（λ_i ∝ i^−β）。
- **先验预测（公式 R_cap 注水）= MAE 2.80 nats, bias −2.80**（预测值系统性远低于实测）。
  根因: `R_cap`（来自交互率计数）量级远大于数据实际可达率 → 注水过度、失真塌到 H_floor → 预测失效。
- **反演诊断（真发现）**: 由实测反推 `R_needed = R_of_D(λ_n, 实测超额)`, 拟合得
  `R_needed ∝ lnN 斜率 = −0.46`、`R_needed ∝ lnT 斜率 = +0.83`、`R_cap↔R_needed 相关 = +0.69`。
  → **可达率由数据 T 门控（正相关的 lnT 主导）, 而非容量 N 门控（负相关的 lnN）**;
  且在数据受限区内更大 N 反而更差（lnN 负斜率）。这正是诚实边界: 谱决定预算 D0 与地板,
  但**决定不了可达率 R(N,T)** —— 即 `predictive-gap.md` 的**缺口 #2（架构→可达率）未闭合**。
- **E9 最小实测 loss = 2.483 nats**（dim128, T=300K）; **不可约缺口 = 1.553 nats** = 容量不足 + 优化缺口 + 估计误差三混合（= 未闭合的 R(N,T) 缺口的实测总和）。
- **判定**: 先验预测作为“点预测”不成立（MAE 2.80, 公式率尺度错配）, 但它精确定位了分水岭——
  谱能先验给出 H_floor(0.93) 与 D0(3.69)（下界与预算已量化）, 却预测不到损失地形,
  因为 R(N,T) 是数据受限的、谱无法决定。这把“预测差距账簿”里的缺口 #2 从假设提升为实测确认的边界。

## 6. 与 CPU 冒烟版的对照总表

| 实验 | CPU（小模型弱训练） | GPU（A100 放大） | 一致性 |
|---|---|---|---|
| E11 残差 | 无跳连 L6→0 坍缩 | 无跳连 L4→0 坍缩 | ✅ 强支持 L8（GPU 更强） |
| E12 逆模式 | 12.5× | 2.8×/5.0× | ✅ 方向支持 L7（量级配置相关） |
| E8-8A 普适性 | 比 1.17 | 比 1.27 | ✅ 弱复现 |
| E8-8B T^{-1/2 | 0.9998 平坦 | 0.83 平坦 | ❌ 边界确认（非设计缺陷） |
| E8-8C 谱指数 | +0.370 | +0.461 | ✅ 支持（GPU 更强） |
| E9 规模 | 双区间 | 双区间 + crossover 起点 | ✅ L2 双区间（GPU 更干净） |
| E13 先验预测 | MAE 0.472 未过（公式版） | MAE 2.80 不成立；反演得 R_needed∝lnT +0.83/∝lnN −0.46 → 可达率数据门控（缺口 #2 边界） | ✅ 结论一致: 谱给预算给不到地形, 分水岭成立为诚实边界 |

## 7. 诚实边界

- 全部为单语料族（仓库 markdown/lean/tex）、3 seeds、弱训练（400–2000 步）的**验证性**实验, 非大规模基准。
- E9 卡在数据受限区 → 幂律-over-N 与 β-fit 不可定义；进入参数受限区需更大语料（>1M 字符）或更大模型。
- E8-8B 的 T^{-1/2} 是真边界；若要测“数据越多子空间越确定”, 应换指标（如子空间方差而非两半距离）或更多模型。
- E12 的 2.8× 是下界（ES 维度诅咒未充分放大）；ES/爬山超参已调优, 但理论上逆模式优势应随维度单调放大。
- E13 的 H_floor 与 E9 最小 loss 来自不同语料快照（docs/wiki 在两次实验间增长）, 缺口为近似对照, 量级结论稳健。
