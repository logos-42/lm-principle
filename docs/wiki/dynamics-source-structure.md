# 结构作为动力学来源：四组件的第一性解释与实验纲领

> 用户推进（2026-10-20）: "我们实际上是把产生智能的结构，当成是一种动力学的
> 来源来设置和计算的" —— 本文把这个概念精确化，并回答: 现有解释（L2/L6/公设
> 体系）能否覆盖**规模法则（含截止）**、**反向传播**、**残差连接**、
> **共同基子空间（UWS）** 四件事; 以及为支撑推导所必需的实验现象清单。

## 1. 概念修正: 结构是动力学的来源，不是动力学的舞台

旧（力学式）图景: 结构 = 状态变量 s(t)，动力学 = 外加更新规则作用在 s 上。
**本框架的图景**: 向量场由结构自身生成——F(s) = −∇_s D(s; 𝒫) 是结构与其
感知流耦合的张力；抽掉结构，"力"不复存在（没有外部施力者）。

精确形式: 研究对象是**对** (s, 𝒫) ∈ 𝒮 × 𝒫，动力学是**闭环流**
Φ: (s, 𝒫) ↦ (s', 𝒫')——智能体作用于世界，世界给出新感知（开环力学没有这一项）。
两个后果:
1. **内生向量场**: 无需外源力，落差梯度由耦合自身产生（§3 "无外部施力者"的加强版）
2. **共生态空间**: 态空间本身随流演化（吸引子是涌现物，不是先天几何）
⟹ 这正面回答了"为什么叫认知动力学而非力学": 物理力学 = 外源力场 + 固定相空间;
认知动力学 = 内生向量场 + 共生态空间 + 闭环耦合。

## 2. 四组件的第一性解释

### 2.1 规模法则与其截止（L2 的推导目标）

**机制链**（每环都有对应定律/已证定理）:
1. A2: 感知流 𝒫 有内在结构，其协方差谱 {λ_i} 决定率-可达失真
2. L1（容量）: 组合容量随参数增长（`CognitiveDynamics.lean` 的 2^k 容量定理）
3. A4: 训练 = 降失真; N 参数可达的最优 ≈ 最优率-R(N) 压缩器
4. ⟹ **L(N) ≥ D*(R(N)) + H(𝒫∣𝒾*)** —— 残余失真 + 不可约熵

**为什么有效**: λ_i 幂律衰减（UWS suitability 的 α∈[2,6] 正是此）⟹ D*(R)
幂律下降 ⟹ 观察到的 L ~ N^{−α}（Lean 已有 `scaling_law_strict_anti` 内核）。
**在哪里截止**: 双地板——① H(𝒫∣𝒾*) 不可约熵（世界不可观测部分）;
② 有限数据 T 下谱估计误差 ~ T^{−1/2}（UWS Thm 3.7）⟹ 数据地板。
Chinchilla  compute-最优分配 = 同一失真泛函下参数增长与数据增长的经济平衡。
**已出现的实证呼应**: E7 深度扫描在 Δ 噪声地板 ±0.17 处震荡（层数维度的地板）;
E8 的 T 扫描直接测第 ② 项。

### 2.2 反向传播（新候选定律 L7）

在本框架内，反向传播不是算法选择而是**被迫的**:
1. A4 要求更新沿 −∇_s D(s)——方向由公设给定
2. D(s) 是**标量**（失真/期望），参数数 n 巨大
3. 定理（自动微分复杂性，Griewank 1989）: 标量目标的梯度，逆模式代价
   ≤ 4× 前向，而顺模式代价 ~ n× 前向
4. ⟹ **L7（候选）**: 标量失真目标 + 组合结构 ⟹ 逆模式自动微分是渐近最优的
   梯度计算；反向传播 = A4 的高效实现，非工程巧合

**附带解释"人脑不反向传播"**: 脑的选择原理作用于种群/寿命尺度（持续耦合 +
复制子动力学），不是固定数据集上的标量拟合——不需要也不允许全局逆模式。
这与此前"人脑靠适应性不靠扩参"的论点接龙。

### 2.3 残差连接（新候选定律 L8）

A4 的离散形式 Δs = −η∇D(s) 是梯度流的离散化；残差实现 s_{l+1} = s_l + f(s_l):
1. **恒等路径 = 流的"位置记忆"（惯性项）**: 状态跨层保留参照系，否则每层
   替换状态、组合可坍缩（已证: `residual_no_collapse` 距离 ≥ (1−c)^n;
   FFN 无恒等路径可坍缩, InfoDynamics 定理 7）
2. **几何读法**: 跳连 = 沿流的平行移动；没有它，跨层迭代点不可比较——
   这正是"深层循环为什么要返回"的答案（返回 = 恒等路径提供的参照系）
3. **门控读法**: LSTM 门控保留 α^t（已证）= 可控惯性
4. ⟹ **L8（候选）**: 迭代压缩动力学中，恒等/门控回馈是防坍缩 + 跨层可比较性
   的充要结构；深度有效当且仅当存在回馈（已证内核 + 待组装的充要性陈述）

### 2.4 共同基子空间（UWS = L3 的经验面孔）

UWS 观察: 独立训练的网络跨任务/初始化收敛到共享低维谱子空间
（共享基 U + 任务系数 C 的仿射分解 μ + C ×_p U）。
本框架的解释:
1. L3: A4 动力学的吸引子 = 感知流**二阶矩算子的主子空间**——由数据统计决定，
   不由随机初始化或任务标签决定
2. ⟹ 任务共享同一感知流统计 ⟹ 共享同一吸引子（UWS 的"普适性"）
3. UWS 分解的**共享基 = 数据协方差 top-k 特征向量**；**任务系数 = 特异部分**
   ——与我们的"比特给容量、几何给内容"（P3 修复）精确对应
4. UWS 的模型合并（无数据、解析计算、超六种基线）= 共享基上的凸组合，
   误差由子空间残差界定——L6 凸组合定理族（`attention_error_bound`/
   `moe_error_bound`）的适用范围
5. **可证伪的预测**: 子空间维数 = 有效秩 = 谱尾穿过失真预算的位置; 换数据
   分布 ⟹ 换吸引子（跨域不共享的部分）

## 3. "为什么会产生智能"——体系内的回答

智能不是奇迹，是**闭环压缩动力学在选择压下的通形**:
1. 世界可压缩（否则无认知系统能持存——定义性）
2. 率受限耦合（A2）迫使压缩
3. 选择（D4）过滤掉劣压缩者
4. 组合给出容量（L1），下降给出方向（A4），softmax 给出选择算子（L6），
   逆模式给出高效实现（L7），恒等路径给出跨层记忆（L8）
⟹ **任何持存的认知系统必然呈现这些形式**——智能 = "不压缩即死"动力学的
不动点，从内部看就是这个样子。推导链的每一环都有（或将有）实验对应（§4）。

## 5. 诚实边界

- §2 的机制链是**推导路线图**，不是已完成证明: L2/L3/L7/L8 均为目标态
  （L6 半程、L4 已证是仅有的机器验证项）
- L7 的 Griewank 界是文献定理，Lean 化工作量中等（需形式化 AD 复杂性，
  可能超出近期范围——可先以实验 E12 支撑）
- E8-E12 都是小模型冒烟测试，不构成对定律的验证/证伪，只提供"可见的效果"
  与量级检查
- §3 的回答依赖 D4 的定义性（见 selection-principle-derivation.md）——
  可证伪内容全在 L2-L8 及其实验对应上
