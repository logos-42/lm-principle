# 公设独立性分析（审稿人第一问）

> 问题: A4（落差驱动）能否从 A1-A3 推出？公设集是否极小？
> 结论先行: **不能完全推出，但缺的东西比想象的小**——A4 可三分解，
> 其中"目标函数"和"下降方向"两部分可以从 A2+A3 用无损归纳/通用预测的
> 遗憾界**推导**出来；真正不可再还原的只剩一块**选择原理**（持存过滤器），
> 而它正是牛顿第一定律（惯性）在那个位置的类比物：单独不可证伪，
> 靠锚定的整个定理体系获得意义。

## 1. A4 的三分解与可推导性判定

A4 原文: 结构沿感知压缩失真下降的方向演化（Δs ∝ -∇_s D(s)）。
拆成三个独立主张:

| 部分 | 内容 | 可从 A1-A3 推导? | 依据 |
|---|---|---|---|
| A4-a 动力学存在性 | 结构确实随时间演化（而非静止） | **否** | A1-A3 都是静态陈述；一个冻结的查找表完全满足它们。需外部输入"世界在变/系统需持续耦合" |
| A4-b 目标函数 | 演化的目标是压缩失真 D（而非任意泛函） | **是（给定选择原理）** | Solomonoff 遗憾界: 任何可计算预测器的累积惊奇减通用预测器的累积惊奇 ≤ O(1)（描述长度）。持续耦合要求预测不脱钩 ⟹ 可观测的持存结构其累积惊奇 ≈ 可达最小 ⟹ 目标 = 惊奇/失真，无任意性 |
| A4-c 下降方向 | 沿 -∇D 而非 +∇D 或随机走 | **是（数学事实）** | 陡降定理: 光滑泛函的最速下降方向 = 负梯度；上升使耦合脱钩（A3: 信息结构退化），被选择原理过滤掉 |

**关键引理（A4-b 的推导链）**:
1. A2: 感知流 p₁,p₂,... 经率受限信道进入结构
2. 结构 s 维持预测分布 q_s(p_{t+1} ∣ p_{≤t})；落差 = -log q_s(p_{t+1})
3.  minimax 遗憾界（通用归纳定理）: ∀可计算 q, Σ落差(q) - Σ落差(通用预测器) ≤ K(q)（常数）
4. 选择原理（待设为公设的仅剩项）: 累积落差增长快于最优可达值的结构失去耦合 ⟹ 不是持存的认知主体
5. ⟹ 可观测持存结构满足"累积落差 ≈ 最小可达" ⟹ 更新沿期望落差的陡降方向
6. 非凸/有限算力限制 ⟹ 局部下降 + 架构依赖（这正是 L3 吸引子与临界性的入口，
   也是"为什么需要特定结构组合"的力学位置）

第 3 步是实定理（Solomonoff/Legendre-Webster 遗憾界）；第 4 步是唯一的
非数学输入。**所以 A4 的"软件部分"（目标+方向）可推，"硬件部分"（世界确实
按持存过滤）不可推。**

## 2. 独立性检验（每个公设都有不满足其他公设的模型）

| 模型 | 满足 | 不满足 | 说明 |
|---|---|---|---|
| 冻结压缩器（JPEG/PCA 码本） | A1,A2,A3 | A4 | 静态压缩完美成立，无智能动力学 ⟹ A4 不被 A2 蕴含 |
| 盲选择过程（随机变异+选择，无感知） | A4（弱化版） | A2 | 进化选择无感知通道也能运行 ⟹ A2 不被 A4 蕴含 |
| 时钟 | 有动力学 | A2 | 用户原类比: 有时钟式的动力学但无感知通道，不智能 |
| 查找表（无训练） | A2（静态） | A4-a | 有感知输入但无演化 ⟹ 动力学存在性必须外供 |

⟹ **A2 与 A4 相互独立**；智能需要两者（时钟反例 + 冻结压缩器反例各挡一半）。

## 3. 公设集的极小化（4 条 → 2 条 + 1 过滤器）

| 原公设 | 处置 | 理由 |
|---|---|---|
| A1 组合本体 | **降为定义 + 定律 L1** | 本体部分（"智能定位于组合"）是定义不是公设；必然性部分可由 A2 + 容量引理推出: 单单元假说类容量有上界（VC 维 ≤ 参数+1 / 覆盖数），任务所需容量随世界熵无界增长 ⟹ 必须组合。**A1 从公设降格为 L1** |
| A2 感知压缩 | **保留为第一公设** | 不可推导的实质本体论主张（感知 = 率受限有失真信道）。类比光学"光沿直线传播" |
| A3 信息度量 | **降为测量约定** | 近乎重言式（Shannon 框架已内蕴）；其实质内容是负面边界（比特不给意义），是自认限制而非主张 |
| A4 落差驱动 | **拆解后只保留选择原理 A4'** | 目标+方向可推（§1）；剩余不可还原部分 = 持存过滤器 |

**极小公设集（新架构）**:
- 定义 D1-D3: 结构（状态空间）/ 感知（媒介）/ 比特（量具）
- **公设 I（压缩）**: 感知 = 率受限保信息信道；结构质量 = 失真 D(s)。（原 A2）
- **公设 II（选择）**: 持存的认知主体是其感知耦合质量的优胜者；等价地，
  可观测的智能演化沿落差下降方向。（原 A4 的不可还原残核）
- 容量引理（待证定理）: 单单元假说类容量有参数上界。
- 全部其余（A1 必然性、L1-L5）为导出量。

## 4. 公设 II 的辩护（为什么它可以当公设）

1. **惯性辩护**: 牛顿第一定律单独也不可证伪（"不受力则匀速"是定义性的），
   它靠锚定的整个体系（F=ma → 开普勒 → 潮汐）获得意义。公设 II 同理:
   单独看近于重言（"持存者持存"——这也正是自由能原理受到的批评），
   但它的 L2-L5 推论（规模律形状、吸引子谱结构、最优深度、预测充分性）
   是实质且可检验的。**公设的合法性来自定理，不来自新颖性。**
2. **机制辩护**: 选择过滤器有实现机制——种群层面的复制子动力学
   （预测更优的结构更多被复制/保留），不是魔法。
3. **最小性辩护**: 它是唯一不可再还原的输入；砍掉它，静态信息论
   （率-失真）仍然成立但智能动力学全部消失。

## 5. 由此产生的新问题（下一轮候选）

1. **公设 II 本身能否从更深原理导出?** 候选路线:
   热力学（Landauer: 擦除比特有能耗，持存结构必须低惊奇才能低耗散）、
   算法信息论（通用归纳的最优性 ⟹ 任何持存计算过程渐近服从它）、
   复制子动力学（选择的形式化）。这是全理论最深的一个洞。
   **✅ 已攻克（同日）: 三条路线全部失败，但失败本身证明了公设 II 是
   定义性的（如同 F≡ma），移入定义 D4，公设降为 1 条。详见
   `selection-principle-derivation.md`。意外产出 L6（softmax 第一性来源）。**
2. **率上限 R 从哪来?** 公设 I 中的比特率上限（有限带宽/参数量）是经验量；
   它是否也可从"物理实现的计算密度极限"导出，决定公设 I 的硬度。
3. **非凸性的位置**: A4-c 只给局部下降方向；全局结构（吸引子、临界性）
   全是定理而非公设——这正是 L3 的工作，也是"架构为什么重要"的力学位置。

## 6. 对论文写作的意义

- 论文 §2 只摆 **2 条公设 + 3 条定义**，比原来的 A1-A4 更接近牛顿式的最小集
- §3 放 A4 三分解推导链（含遗憾界引理）——这是全章最硬的数学，
  直接回应"你的 A4 是不是抄自由能原理"的审稿意见: 不是抄，是推
- §4 放 L1-L5；其中 L1（组合必然性）吸收原 A1，有 VC 维证明路线
