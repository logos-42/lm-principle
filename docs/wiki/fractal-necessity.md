# 分形的必要性——知识编译页（第三季第3期）

> 来源: `docs/wiki/shape.md`（用户提供，super_frontier_radar 系列）

## 核心论点（三条法则）

1. **默里定律**: 血管分叉点满足 r³ = r₁³ + r₂³ ⟹ 最优子/母半径比 =
   2^(-1/3) ≈ 0.79。这是**从流体输送能量最小化推导**的数学最优解，
   不是经验拟合。适用域: 血管、河流、根系、支气管。
2. **分形 = 空间填充的最优解**: 覆盖全部空间（约束一）× 最短管道/最低
   能耗（约束二）——只有分形结构能同时满足。脑皮层折叠是
   "表面积/体积最大化"的最优解。
3. **深度不是越深越好**: 最优深度由**任务的分形维数**决定，不由层数决定。
   大脑皮层六层 = 能量预算下分形结构能维持的最大有效深度。
   深层堆叠收益递减（边际提升↓，成本线性↑，梯度退化↑）。

## 实验数据（fractal_necessity.py, 三个实验）

| 实验 | 机制 | 结果 |
|------|------|------|
| 一 默里定律 | r³ 守恒, 扫描分叉比率 | 0.50→能耗 1.9e11（阻力爆炸）; 0.79→1.3e7; 0.90→1.0e5（但维护成本 7×） |
| 二 分形 vs 均匀 Transformer | 同任务, 层特性分形缩放 | 均匀 400,641 参数 vs 分形 301,569 参数（**-25%**）, 损失几乎相同 (113.61 vs 113.62) |
| 三 最优深度搜索 | 扫 2-18 层 | 两者最优深度均为 2 层；4 层起损失断崖 (41-72+), 6 层以上 80-114 |

**诚实边界（作者自述）**: 实验一的简化能耗公式（阻力 1/r⁴ + 维护 r²）
不含**心脏做功项**（∝ 总截面积）——因此 0.90 的总能耗反而低于 0.79。
默里定律的完整最优性需要三项成本同时最小化。这是简化模型的边界暴露，
也是"分形维数有限性"物理根源的一部分。

## 与 lm_principle 的接口——候选可形式化命题

（以下命题是**候选素材**，等待用户确认假设后逐一 Lean 验证）

### C1. 默里定律的最优性（变分/优化）
- 命题: 在单分叉点，令 C(r) = α/r⁴ + βr² （阻力 + 维护，α,β>0），
  子管半径受 r³ = r₁³ + r₂³ 约束且 r₁ = r₂（对称分叉）⟹
  能量最小化的最优比 r₁/r = 2^(-1/3)。
- Lean 路线: 单变量实分析最优化（min 的闭式解），
  可先形式化"r₁/r = 2^(-1/3) 是驻点 + 二阶条件"。
- 状态: 待假设确认。

### C2. 分形维数与最优深度的关系
- 命题: 覆盖 D 维空间、每级分支数 b、线性收缩比 s 的分形树，
  其分形维数 D = log b / log(1/s)（自相似维数公式）。
  给定 D，最优级数（深度）n* 由"覆盖率饱和"决定：s^n·b^n → 1。
- Lean 路线: 幂/对数恒等式 + 单调性（mathlib 有 Real.log/pow 基础）。
- 状态: 待假设确认。与 LMT-twister V34 发现呼应:
  "训练容量可规模破解（d_model↑），泛化独立封顶（规模无效）"——
  即"深度/容量不是越深越好"的实证版本。

### C3. 分形 Transformer 连接密度幂律
- 命题: 连接密度 δ(d) = (1-d)^(D-1)（d = 归一化层深）在 D>1 时
  单调递减且凸（浅层密集、深层稀疏）。
- Lean 路线: 实函数单调性/凸性（mathlib 完备）。
- 状态: 待假设确认。与 Transformer.lean 的置换等变/凸组合定理同族。

### C4. 深度收益递减的形式化（可选）
- 命题: 若每层边际提升 η_k 满足 η_k = Θ(1/k^p)（p>1），
  则有限深度 L* = argmin_L Σ_{k≤L} η_k - λL 存在且有限。
- Lean 路线: 级数收敛 + 最优化（mathlib 完备）。
- 状态: 待假设确认。
