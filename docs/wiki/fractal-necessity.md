# 分形的必要性——知识编译页（第三季第3期）

> 来源: `docs/wiki/shape.md`（用户提供，super_frontier_radar 系列）

> **2026-08-12 更新: 核心命题已在 `LmPrinciple/Fractal.lean` 中 Lean 验证（8 定理）。**

## 核心论点（三条法则）

1. **默里定律**: 血管分叉点满足 r³ = r₁³ + r₂³ ⟹ 最优子/母半径比 =
   2^(-1/3) ≈ 0.79。这是**从流体输送能量最小化推导**的数学最优解，
   不是经验拟合。适用域: 血管、河流、根系、支气管。
2. **分形 = 空间填充的最优解**: 覆盖全部空间（约束一）× 最短管道/最低
   能耗（约束二）——只有分形结构能同时满足。脑皮层折叠是
   "表面积/体积最大化"的最优解。
3. **深度不是越深越好**: 最优深度由**任务的分形维数**决定，不由层数决定。
   大脑皮层六层 = 能量预算下分形结构能维持的最大有效深度。
   深层堆叠收益递减（边际提升↓，成本线性↑，梯度退化↑）。

## 实验数据（fractal_necessity.py, 三个实验）

| 实验 | 机制 | 结果 |
|------|------|------|
| 一 默里定律 | r³ 守恒, 扫描分叉比率 | 0.50→能耗 1.9e11（阻力爆炸）; 0.79→1.3e7; 0.90→1.0e5（但维护成本 7×） |
| 二 分形 vs 均匀 Transformer | 同任务, 层特性分形缩放 | 均匀 400,641 参数 vs 分形 301,569 参数（**-25%**）, 损失几乎相同 (113.61 vs 113.62) |
| 三 最优深度搜索 | 扫 2-18 层 | 两者最优深度均为 2 层；4 层起损失断崖 (41-72+), 6 层以上 80-114 |

**诚实边界（作者自述）**: 实验一的简化能耗公式（阻力 1/r⁴ + 维护 r²）
不含**心脏做功项**（∝ 总截面积）——因此 0.90 的总能耗反而低于 0.79。
默里定律的完整最优性需要三项成本同时最小化。这是简化模型的边界暴露，
也是"分形维数有限性"物理根源的一部分。

## Lean 验证结果（LmPrinciple/Fractal.lean, 8 定理全绿）

**论证链**: 自由能 F = 误差², 网络 = 逐层降自由能。

| 定理 | 内容 | 对应命题 |
|------|------|---------|
| `prefix_allocation_optimal` | 收益递减时预算集中前缀 ≥ 均匀平摊 | 分形比均匀下降更快（核心） |
| `residual_contraction_decay` | 残差 c-收缩 ⟹ 误差 ≤ cⁿ\|e\| 指数衰减 | 残差稳定传播 |
| `free_energy_exponential_decay` | 自由能 ≤ (cⁿ)²·F₀ 指数下降 | 残差 ⟹ 自由能指数降 |
| `attention_error_bound` | QKV 输出 = V 凸组合 ⟹ 误差 ≤ 最差记忆 | QKV 模块误差界 |
| `moe_error_bound` | 门控归一 ⟹ 误差 ≤ 最差专家 | MoE 模块误差界 |
| `fractal_dimension_scale_invariant` | D = log b/log(1/s), n 级缩放不变 | 分形维数定义 |
| `connection_density_strict_anti` | (1-d)^(D-1) 随深度严格递减 | 浅层密集深层稀疏 |
| `fractal_beats_uniform` | 分形前缀分配 ≥ 均匀 (Δ 递减) | 完整结论 |

**回答核心问题**（QKV+残差+MoE 在分形结构上自由能下降速率更高吗）:
- **是, 数学上可证**: 只要每层自由能下降量 Δ_k 严格递减（深度收益递减——
  实验三的断崖正是实证）, 分形组织（预算前缀集中 + 深层幂律稀疏）的总下降
  ≥ 均匀堆叠（定理 1）。深层稀疏省下的成本转移到高收益浅层。
- **高维实现机制**: ①凸组合（凸包）——注意力/MoE 输出被限制在凸包内,
  误差有界（定理 4/5）；②收缩映射——残差/RNN 的 Lipschitz 常数决定
  自由能指数下降速率（定理 2/3）；③幂律稀疏 (1-d)^(D-1)——分形维数 D
  的直接函数（定理 7）。

## 候选可形式化命题（C1-C2 已证, C3-C4 待）

### ✅ C1 默里定律最优性（Murray.lean, 已 Lean 验证）
- `murray_symmetric_ratio_cube`: 流量守恒 r³ = r₁³ + r₂³ + 对称分叉
  ⟹ (r₀/r)³ = 1/2——比率 ρ = 2^(-1/3) ≈ 0.79 被守恒律锁定
- `symmetric_branch_minimizes_maintenance`: 2r₁r₂ ≤ r₁²+r₂²
  （对称 = 维护成本最小）
- 诚实边界: 三项成本（阻力+维护+做功）的**完整变分最优性**（含导数）
  留待 Analysis.Calculus 形式化——本次证明守恒+对称的代数部分

### ✅ C2 最优深度存在条件（Murray.lean, 已 Lean 验证）
- `depth_beyond_threshold_useless`: 边际收益最终 < 边际成本
  （∃k₀, ∀k≥k₀, Δ_k<λ）⟹ 超过 k₀+1 层严格更差
- `optimal_depth_exists`: 递减收益 + 正成本 + 收益最终低于成本
  ⟹ 最优深度存在且 ≤ k₀+1（"深度不是越深越好"的精确条件）
- 分形连接密度 (1-d)^(D-1) 严格递减（Fractal.lean）天然满足收益递减条件

### C1. 默里定律的最优性（变分/优化）
- 命题: 在单分叉点，令 C(r) = α/r⁴ + βr² （阻力 + 维护，α,β>0），
  子管半径受 r³ = r₁³ + r₂³ 约束且 r₁ = r₂（对称分叉）⟹
  能量最小化的最优比 r₁/r = 2^(-1/3)。
- Lean 路线: 单变量实分析最优化（min 的闭式解），
  可先形式化"r₁/r = 2^(-1/3) 是驻点 + 二阶条件"。
- 状态: 待假设确认。

### C2. 分形维数与最优深度的关系
- 命题: 覆盖 D 维空间、每级分支数 b、线性收缩比 s 的分形树，
  其分形维数 D = log b / log(1/s)（自相似维数公式）。
  给定 D，最优级数（深度）n* 由"覆盖率饱和"决定：s^n·b^n → 1。
- Lean 路线: 幂/对数恒等式 + 单调性（mathlib 有 Real.log/pow 基础）。
- 状态: 待假设确认。与 LMT-twister V34 发现呼应:
  "训练容量可规模破解（d_model↑），泛化独立封顶（规模无效）"——
  即"深度/容量不是越深越好"的实证版本。

### C3. 分形 Transformer 连接密度幂律
- 命题: 连接密度 δ(d) = (1-d)^(D-1)（d = 归一化层深）在 D>1 时
  单调递减且凸（浅层密集、深层稀疏）。
- Lean 路线: 实函数单调性/凸性（mathlib 完备）。
- 状态: 待假设确认。与 Transformer.lean 的置换等变/凸组合定理同族。

### C4. 深度收益递减的形式化（可选）
- 命题: 若每层边际提升 η_k 满足 η_k = Θ(1/k^p)（p>1），
  则有限深度 L* = argmin_L Σ_{k≤L} η_k - λL 存在且有限。
- Lean 路线: 级数收敛 + 最优化（mathlib 完备）。
- 状态: 待假设确认。
