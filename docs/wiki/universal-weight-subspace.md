# 普适权重子空间假说（The Universal Weight Subspace Hypothesis）

> 来源: arXiv:2512.05117v3 — Kaushik, Chaudhari, Vaidya, Chellappa, Yuille（JHU，
> 2025-12 首发 / 2026-10-05 v3, CC BY 4.0）。manifest: `universal-weight-subspace`。
> 本文是 compile-first 产物：论文要点 + 候选可形式化命题 CD1-CD5。
>
> **定位更新（2026-10-20，同日）**: 经用户定调，认知动力学不走"从经验假说反推
> 智能"的路线（牛顿秩序：先本体后公设再推导再检验）。本论文从主线降级为
> **对照物/交叉验证**：其现象（训练收敛到共享低维谱子空间）恰是公设 A4 的
> 差落驱动动力学应有的推论形态（L3 吸引子），可作为 L3 的间接经验支持，
> 但不是出发点。主框架见 `cognitive-dynamics.md`。

## 核心主张

同一架构下、跨任务/跨初始化/跨领域训练的深度网络，其权重**系统性地收敛到
少数共享的低维谱子空间**，与初始化、任务、数据集无关。1200+ 模型实证
（500 Mistral-7B LoRA、500 ViT、50 LLaMA3-8B、177 GPT-2、Flan-T5/GLUE、
ResNet-50×9、StyleGAN2×20、SDXL LoRA）：**≤16 个主方向**即可捕获大部分方差；
存储缩减 >100×（ViT 集 150 GB → 单一子空间模型；LLaMA 集 1.6 TB）。

**为什么这是认知动力学的经验锚点**：训练动力学不是满空间游走，而是被漏斗进
一个低维仿射吸引子 Ŵ = μ + C ×_p U^(p)。"智能收敛到特定组合结构"从猜想变成
可测量的现象；剩下的是从第一性原理**推导**它——论文只给了条件性理论
（作者明确：不证明 universality）。

## 方法：Truncated Zero-Centered Shared HOSVD（Algorithm 1）

对同架构 M 个模型逐层做模态谱分解（实验用 order 1–2）：

1. 堆叠：𝒳 ∈ ℝ^{M×I₁×…×I_P}（模型轴只用于估计共享因子，本身不被压缩）
2. 零中心化：μ = 对模型轴 + 未分解模态求特征均值；X_c^(m) = W^(m) − μ
3. 模态展开 + 薄 SVD：X_{c,(p)} = Ũ⁽ᵖ⁾Σ⁽ᵖ⁾Ṽ⁽ᵖ⁾ᵀ
4. 截断：取最小秩 r̂_p 使累计解释方差 ≥ 阈值 τ
5. 模型专属核张量：C⁽ᵐ⁾ = X_c⁽ᵐ⁾ ×_p U⁽ᵖ⁾ᵀ
6. 重构：Ŵ⁽ᵐ⁾ = μ + C⁽ᵐ⁾ ×_p U⁽ᵖ⁾

|P|=1 时等价于对所有模型的 mode-p 纤维做 PCA。
**Universal Subspace 定义**：零中心化权重的共享线性子空间；原参数坐标下是
仿射空间（μ 广播到权重形状）。

**数据无关适用度（suitability, §B.1）**：对 W^T W 经验谱密度尾部拟合幂律，
得重尾指数 α_{l,m}（遵循 Martin & Hinrichs 2025）；保留条件：层均值
α∈[2,6]、标准差 ≤1、至少半数估计落在 [2,6]、层得分 q_l ≥ 0.2。

| ViT（500 个公开预训练） | 未过滤、无训练数据访问 | 16 维子空间：IID **94.1% vs 94.4%** 全量；OOD **87.8% vs 91.3%**；500 个可并为单一子空间模型，**~100×** 内存缩减 |

| SDXL LoRA | 文生图 | 平均 CLIP 略升：**19.83 vs 19.73** |

**合并结论**：共享基 + 每任务稀疏系数可替换数百个全量模型；合并系数由子空间几何
**解析计算**，无需验证数据/超参搜索，平均精度优于 RegMean、Task Arithmetic、
TIES、DARE-TIES、KnOTS 等六种梯度-free 基线。

## 条件性理论（作者明确标注：是"条件动机"，非 universality 的证明）

- 任务二阶矩算子：𝒮 = 𝔼_t[f_t*⊗f_t*]，top-k 特征子空间 H_k*，特征间隙 γ_k = λ_k−λ_{k+1}
- Lemma 3.5（集中性）：‖𝒮̂−𝒮‖_op ≤ B²/√T·(1+√(2ln(1/δ_T)))
- Lemma 3.6（Davis–Kahan）：‖P̃_k−P_k‖_op ≤ (2/γ_k)‖𝒮̃−𝒮‖_op
- Theorem 3.7（两层收敛）：‖S̃−S‖_op ≤ c₁B²√(ln(c₂/δ)/T) + (2Bη̄+η²̄)；
  **跨任务误差按 T^{-1/2} 衰减，与每任务误差 η̄ 分离**
- Corollary 3.11：学习子空间的超额投影风险 ≤ Σ_{i>k}λ_i + (2tr(𝒮)/γ_k)(…)
- Proposition 3.9：围绕共享 θ₀ 线性化的理想 regime 下，预测子协方差与函数相关
  权重协方差**酉等价**；Algorithm 1 在三方面偏离该 regime（逐模态分解、
  特征级中心化、多数集合从零训练无共享 θ₀）
- Theorem A.5：在"层间谱选择 + 集中性 + 特征间隙 + 稳定性"假设下，两个独立
  训练网络的逐层主子空间满足递归
  d(U_A,U_B) ≤ (2/δ_l)(2ε_l + L_l·d(前一层))；若 ρ_l = 2L_l/δ_l < 1 则收缩

## 作者自述局限

1. 理论仅为**条件性**：不证明 universality，不保证低秩子空间存在
   （谱尾 Σ_{i>k}λ_i 是否小是经验问题）
2. Algorithm 1 与理想线性化 regime 有**三点偏离**（逐模态分解 / 特征级中心化 /
   多数集合从零训练无共享 θ₀）
3. 近似质量**依赖模型数量与质量**（9 ResNet / 20 StyleGAN 的 q_all≈0.02–0.06，
   应视为下界/压力测试）
4. "理想 universal subspace"假说未验证；**跨架构子空间比较开放**；
   能否显式设计架构优化子空间几何开放
5. 核心假设 A.3（训练动力学选择层输入协方差 top-k 子空间）对一般非线性网络
   **尚未建立**；每任务误差 η_t 的具体实例化需额外假设
6. 反思：若网络系统性坍缩到同一子空间 ⟹ 共享 bias/能力/失效模式，
   **多样性缺失是否是根本瓶颈？是否应设计方法主动打破收敛？**
7. 全部实验在单张 A5000 上完成（谱分解可 CPU 运行）

## 对认知动力学的意义（接口）

### 与三原理的对接（修复上一轮识别的三个弱点）

**P1（单元+组合）**：论文范围限定"同架构族"——诚实的一般化：智能不在单元
（神经元/算子）里，在训练动力学收敛到的**组合结构**里。"特定组合" = 普适子空间
中的坐标（任务系数 C⁽ᵐ⁾）；基 U⁽ᵖ⁾ 跨任务共享，系数承载个性。架构差异 ⟺ 不同
架构族的子空间不可直读（局限 4）⟹ P1 的"单元"应弱化为"同族可训练算子"。

**P2（感知=压缩）**：低秩截断就是压缩的**连续版本**（词元 = 离散率，子空间秩 =
连续率）。Theorem 3.7 给出**感知量 T 与吸引子精度的定量律**：跨任务误差
~ T^{-1/2} + η̄——"感知越多，对普适结构的估计越准"有了速率。率-失真视角：
秩 r 是码率，Σ_{i>k}λ_i 是失真，τ 是阈值。

**P3（信息比特）**：比特给"量"不给"意义"——论文的合并实验给出意义的几何操作：
合并系数**仅由子空间几何解析计算、无需数据**，精度超六种基线 ⟹ 语义 ≈ 普适
子空间中的坐标 + 系数变换规则；比特（秩）决定容量，几何决定内容。

### 与现有 Lean 模块的对接（83 定理内核）

| 现有模块 | 对接点 |
|---|---|
| `Fractal.lean`（幂律密度/分形维数） | 论文保留层的判据就是谱尾幂律指数 α∈[2,6]——**可训练层 = 幂律谱层**，与 `connection_density_strict_anti` 同族 |
| `CriticalPoint.lean`（临界深度） | 幂律谱 ↔ 边际稳定 ↔ edge of chaos（1908.10920 有序/混沌相图临界线："沿临界线初始化的网络信息可任意深度传播"） |
| `InfoDynamics.lean`（VFE） | 训练 = 自由能下降，吸引子 = 下降动力学的极限集；T^{-1/2} 集中律 = 数据量对自由能估计精度的贡献 |
| `Hopfield.lean`（能量吸引子） | 独立训练的网络落进同一谱子空间 = 共享吸引子盆地；`hopfield_retrieval_error_bound` 的指数锁定 ↔ 子空间锁定的指数形式 |
| `Training.lean`（`scaling_law_strict_anti`） | 规模法则的结构解释 = 有效自由度 = 子空间秩；参数超出秩的部分是谱尾冗余（19×/100× 存储节省的直接证据） |
| `ArchCompare.lean`（`residual_no_collapse`） | 残差防"坍缩到点"；子空间版本的问题 = 防"坍缩到低维仿射空间"——分形分配（`fractal_param_allocation`）是反坍缩设计：每参数买更多有效维 |

### 论文留下的定理形状缺口（认知动力学的攻击面）

1. **假设 A.3 未建立**："训练动力学选择层输入协方差 top-k 子空间"——全文理论的
   地基，对一般非线性网络开放
2. universality 只有条件性集中 + Davis–Kahan，无存在性证明
3. 跨架构普适性开放
4. "主动打破收敛"的设计问题（作者反思，与用户"人脑靠适应性不靠扩参"论点共振）

## 候选可形式化命题（CD 系列，待用户确认假设）

### CD1 吸引子存在性（A.3 的线性化版本）
- 命题：线性化训练动力学下，若数据协方差 S 有特征间隙 γ_k，则梯度轨迹的
  极限集投影到 top-k 特征子空间 H_k*。
- Lean 路线：二次型梯度下降闭式解（`RNN.lean` 已有闭式解先例）；
  Davis–Kahan **不在 mathlib**，需自证或降级为"给定扰动界 ⟹ 子空间距离界"的
  泛函分析核心。

### CD2 感知量-精度律（Theorem 3.7 的确定性核心）
- 命题：若经验二阶矩 Ŝ 满足 ‖Ŝ−S‖_op ≤ ε，则 top-k 投影子距离 ≤ 2ε/γ_k
  （Davis–Kahan 核心）。
- Lean 路线：自证 2×2 块情形（谱理论 + 算子范数）；概率集中部分（B²/√T）作为
  **假设输入不证**——与项目"条件性定理"风格一致。
- 实验对照：本地测 T vs 子空间夹角，验证 T^{-1/2}。

### CD3 规模法则的结构形式（有效秩）
- 命题：参数 N、数据协方差谱 {λ_i} 的网络，损失下界
  L(N) ≥ Σ_{i>k(N)} λ_i + σ²；参数超出有效秩的部分是谱尾冗余。
- Lean 路线：复用 `scaling_law_strict_anti`（Training.lean）+ 级数尾部估计
  （Mathlib `Real.summable`/`tsum`）。
- 价值：把"参数不是越大越好"变成定理，直接支撑"适应性 > 规模"论点。

### CD4 可训练层 = 幂律谱层
- 命题：层可训练（信息可传播、不饱和不爆炸）⟺ 谱尾指数 α∈[a,b]（论文
  suitability 的经验窗口 [2,6]）。
- Lean 路线：复用 `Fractal.lean` 幂律 + `CriticalPoint.lean` 边际性；接口
  1908.10920 相图（χ_q*, χ_c* < 1 = 有序；临界线 = 边际）。
- 注意：[2,6] 是经验窗口不是数学界限——形式化时应参数化区间。

### CD5 合并 = 子空间凸组合
- 命题：在普适子空间内，任务系数凸组合的重构误差 ≤ 各任务单独重构误差的
  凸组合（子空间残差内）。
- Lean 路线：直接复用 `attention_error_bound` / `moe_error_bound` 的凸组合
  模式，加仿射结构 μ + Σ c_i C_i。
- 价值：给"语义 = 子空间几何坐标"一个可证的最小内核。

## 本地实验设计（E8，CPU 可复现，对接现有 experiments/ 基础设施）

论文自述谱分解可 CPU 运行；项目已有 torch 2.12.1+cpu + 字符级 LM（E6/E7）。

1. 用现有 char-LM 设置训练 M=12 个小模型：3 seeds × 4 任务变体（或不同数据子集）
2. 逐层堆叠权重，mode-1 HOSVD/PCA，测 top-k 方差捕获 vs k
3. 主夹角（principal angles）跨组度量：同任务不同 seed vs 不同任务——检验"跨任务共享"
4. 扫数据量 T ∈ {10K, 50K, 200K, 1M} 字符，测子空间估计误差 vs T——检验 T^{-1/2}
5. 谱尾指数 α 分布 vs 各层可训练性（loss 下降）——检验 CD4 的经验窗口

**判定**：②③④ 任一显著成立，即为认知动力学的第一个"可看见的效果"。
